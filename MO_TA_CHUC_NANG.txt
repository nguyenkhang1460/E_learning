1. db_config.php
   └─ Kết nối cơ sở dữ liệu MySQL
   └─ Chứa thông tin: host, username, password, database name
   └─ Được include trong mọi file cần truy xuất database

2. composer.json
   └─ Quản lý dependencies của dự án (thư viện PHP)
   └─ Sử dụng thư viện: smalot/pdfparser (đọc file PDF)

🔐 MODULE XÁC THỰC NGƯỜI DÙNG

3. login.html
   └─ Giao diện trang đăng nhập
   └─ Form: email và password
   └─ Link đến trang đăng ký

4. login_process.php
   └─ Xử lý đăng nhập người dùng
   └─ Kiểm tra thông tin trong database
   └─ Tạo session khi đăng nhập thành công
   └─ Chuyển hướng đến dashboard tương ứng (admin/user)

5. register.html
   └─ Giao diện trang đăng ký tài khoản mới
   └─ Form: full_name, email, password, role (Teacher/Student)

6. register_process.php
   └─ Xử lý đăng ký tài khoản mới
   └─ Mã hóa password
   └─ Lưu thông tin vào bảng users

7. logout.php
   └─ Đăng xuất người dùng
   └─ Hủy session
   └─ Chuyển về trang đăng nhập

8. admin_dashboard.html
   └─ Trang chủ dành cho quản trị viên

   └─ Quản lý người dùng và lớp học

9. user_dashboard.php
   └─ Trang chủ người dùng (giáo viên/học viên)
   └─ Hiển thị danh sách lớp học đã tạo/tham gia
   └─ Nút tạo lớp học mới hoặc tham gia lớp học

10. create_class.html
    └─ Giao diện tạo lớp học mới
    └─ Form nhập: tên lớp, mô tả

11. create_class_process.php
    └─ Xử lý tạo lớp học mới
    └─ Tạo mã mời ngẫu nhiên (invite_code)
    └─ Lưu thông tin lớp vào database
    └─ Người tạo trở thành owner_id

12. join_class.html
    └─ Giao diện tham gia lớp học
    └─ Form nhập mã mời (invite_code)

13. join_class_process.php
    └─ Xử lý tham gia lớp học
    └─ Kiểm tra mã mời có tồn tại
    └─ Thêm user vào bảng class_members

14. manage_class.php
    └─ Trang quản lý chi tiết một lớp học
    └─ Hiển thị: tài liệu bài giảng, bài tập, kết quả chấm điểm
    └─ Phân quyền: chủ lớp (owner) vs thành viên (member)
    └─ Nút xóa tài liệu (chỉ owner)
    └─ Nút xóa bài tập (chỉ owner)

15. upload_lecture.php
    └─ Giao diện tải lên tài liệu bài giảng

16. upload_lecture_process.php
    └─ Xử lý upload tài liệu
    └─ Upload file lên Cloudinary
    └─ Lưu URL và thông tin vào bảng lectures

17. view_lectures.php
    └─ Hiển thị danh sách tài liệu của lớp học
    └─ Cho phép xem/tải xuống tài liệu

18. manage_lectures.php
    └─ Quản lý tất cả tài liệu (dành cho owner)
    └─ Chỉnh sửa, xóa tài liệu

19. edit_lecture.php
    └─ Chỉnh sửa thông tin tài liệu
    └─ Cập nhật tiêu đề, thay đổi file

20. delete_lecture.php
    └─ Xóa tài liệu khỏi database
    └─ Xóa file trên cloud (Cloudinary)
    └─ Chỉ owner mới có quyền xóa

    └─ Tạo rubric (tiêu chí chấm điểm) cho AI

22. create_assignment_process.php
    └─ Xử lý tạo bài tập
    └─ Upload file đáp án lên Cloudinary
    └─ Lưu thông tin vào bảng assignments

23. add_rubric.php
    └─ Thêm tiêu chí chấm điểm (rubric)

24. view_assignments.php
    └─ Hiển thị danh sách bài tập của lớp học
    └─ Học viên xem bài tập để làm
    └─ Giáo viên xem để quản lý

25. view_assignment_detail.php
    └─ Xem chi tiết một bài tập

26. delete_assignment.php
    └─ Xóa bài tập khỏi hệ thống

29. delete_submission.php

📌 HỌC VIÊN:

2. Tham gia lớp học (join_class.html → join_class_process.php)
3. Xem tài liệu (view_lectures.php)
4. Làm bài tập (view_assignment_detail.php → submit_assignment_process.php)
5. Xem điểm (manage_class.php)

Tables:
- users: id, full_name, email, password, role, created_at
- classes: id, class_name, description, owner_id, invite_code, created_at
- class_members: id, class_id, user_id, joined_at
- lectures: id, class_id, title, file_url, file_type, created_at
- assignments: id, class_id, title, content, answer_key_url, created_at
- rubrics: id, assignment_id, criteria_name, max_score, description
- submissions: id, assignment_id, user_id, student_file_url, ai_score, 
               ai_feedback, submitted_at
